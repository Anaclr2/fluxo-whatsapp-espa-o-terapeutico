
# 💬 Fluxo de Atendimento Automatizado para WhatsApp

LINK: https://funilpro.com.br/A2A7yN

Estrutura visual e lógica de automação de atendimento desenvolvida para captação, triagem de clientes e agendamento via WhatsApp.

![Estrutura do Fluxo no Canvas](fluxo-whatsapp.png)

## 🎯 Objetivo do Funil

- **Boas-vindas:** Saudação inicial automática e apresentação dos serviços.
- **Menu Interativo:** Opções para o cliente escolher entre informações de serviços, localização/como chegar e falar diretamente com um atendente.
- **Qualificação de Leads:** Coleta de nome e necessidade do cliente antes do encaminhamento.

## 🗺️ Mapeamento das Mensagens (Script)

### 1. Mensagem de Boas-Vindas
> *"Olá! Seja bem-vindo(a) ao Espaço Terapêutico Luz e Harmonia! Como posso te ajudar hoje?"*

### 2. Opções do Menu (Botões / Lista)
- **Opção 1:** Ver serviços e valores
- **Opção 2:** Como chegar
- **Opção 3:** Falar com atendente

## 🛠️ Tecnologias & Ferramentas Utilizadas

- **Plataforma:** FunilPRO (Canvas de Automação de WhatsApp)
- **Integração:** Mensagens interativas, redirecionamento de links e recolha de contactos.
